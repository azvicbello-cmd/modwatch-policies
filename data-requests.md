# ModWatch data requests

Operator: **Victor Bello**, for **ModWatch**. Pre-release draft awaiting operational verification; not effective yet.

Use [ModWatch support](https://www.reddit.com/message/compose/?to=Aggravating_Slice533&subject=ModWatch%20Support) to ask about access, correction, or removal of personal information stored by ModWatch.

Include the affected community, the record or information concerned, and the type of request. Send from the affected Reddit account when possible. Never send passwords, identity documents, or unrelated private moderator data. Use redacted screenshots only when needed.

The operator will verify only what is necessary, assess where the information is stored, and explain the removal scope. Information embedded in saved configuration text may require removal from current snapshots, original baselines, and retained before/after records. Removing trigger attribution alone does not remove information inside configuration text. Requests must not depend on another moderator consenting to a valid privacy request.

The proposed privacy update stops collecting trigger moderator names and event IDs and removes legacy fields on successful storage operations after upgrade. It has not yet been verified on the private installation. There is no automatic account-deletion detection or selective configuration-text erasure tool; the operator may need authorized installation management or Reddit assistance to complete a request. Requests remain open until the actual removal is confirmed.

The operator will respond within applicable requirements, request clarification when needed, and confirm completed actions without reproducing removed personal information. This procedure also covers account-deletion concerns. Reddit's own platform data handling is separate from ModWatch's stored configuration history.
